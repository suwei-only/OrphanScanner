# 🛡️ OrphanScanner — 孤儿文件 / 残留扫描器

> 扫描电脑里"已卸载但没删干净"的孤儿文件与僵尸注册表项,支持**可还原的回收站删除**。

![icon](icon.png)

## 为什么需要它?

卸载软件/游戏后,经常留下**孤儿残留**:

- Steam / Epic 库里游戏卸载了,但 `common\` 目录里几百 GB 文件还躺着(SpaceSniffer 看得到,平台却不认)
- 卸载注册表项指向的目录早已不存在(控制面板里的"幽灵软件")
- 各种绿色软件/安装器留下的无主大目录

市面上的工具要么只做"磁盘可视化"(SpaceSniffer),要么只支持单一平台(SteamCleaner)。OrphanScanner 用**三层架构**覆盖全软件来源。

## 三层扫描架构

| 层 | 扫描内容 | 置信度 | 原理 |
|---|---|---|---|
| **层1** | 游戏平台孤儿(Steam / Epic) | 🟢 100% 确定 | 对比平台安装清单(`appmanifest_*.acf` / Epic `.item`)与实际目录,清单里没有 = 卸载残留 |
| **层2** | 注册表僵尸项 | 🟢 高置信 | **四重校验**:安装目录消失 + 卸载器失效 + 进程未运行 + 开始菜单无同名活快捷方式 |
| **层3** | 启发式候选 | 🟠 供人工判断 | 无任何登记的大目录(>200MB、>90天未动),给证据:大小/时间/主程序/存档位置 |

> ⚠️ 启发式候选**无法从原理上 100% 判定**(绿色软件无登记),所以只列证据、绝不自动删。

## ✨ 功能特性

- **♻️ 可还原的删除**:删除 = 移入应用回收站(同盘移动,瞬时完成),误删随时还原;确认不要后再"永久删除"释放空间
- **🛡️ 注册表删除前自动备份**:每个注册表键删除前先 `reg export` 成 `.reg` 存进回收站,一键还原
- **📂 打开所在文件夹**:删除前先看看是什么
- **❓ 一键错误反馈**:全局异常捕获 + 诊断信息收集(系统/版本/磁盘环境),复制后发给开发者即可
- **存档保护**:检测到 Saved/存档类目录会警告
- 扫描全程后台线程,界面不卡;单文件 exe,免安装

## 🚀 快速开始

### 直接使用(推荐)

下载 `OrphanScanner.exe`(单文件,Windows 10/11),双击运行 →「▶ 开始扫描」。

### 从源码运行

```bash
pip install pyinstaller        # 仅打包需要
python orphan_gui.py           # 图形界面
python orphan_scanner.py       # 命令行版(可加 --delete 交互删除)
```

### 打包 exe

```bash
pyinstaller --noconfirm --onefile --windowed --icon icon.ico \
            --name OrphanScanner orphan_gui.py
# 产物: dist\OrphanScanner.exe
```

## 📁 项目结构

```
orphan_scanner.py   核心引擎:三层扫描 + 回收站 + 注册表备份/还原 + 诊断
orphan_gui.py       图形界面(自带 tkinter,无第三方依赖)
make_icon.py        图标生成脚本(Pillow)
icon.ico / icon.png 应用图标
```

## 🧪 删除安全性设计

删除流程分两段,防止误删:

```
扫描 → 选中 → 移入回收站(可还原) → 确认无误 → 永久删除(释放空间)
              ↑ 任何一步反悔都来得及
```

- 移入回收站 = 同盘改名移动,**瞬时完成**,几百 GB 也一样快
- 注册表键 = 先导出 `.reg` 备份再删(HKLM 需 UAC 授权)
- 回收站管理窗口支持:还原选中 / 永久删除选中 / 清空全部

## 🐛 反馈问题

程序内点击「❓ 反馈问题」→「📋 复制诊断信息」,把内容连同问题描述发到
[GitHub Issues](../../issues)(或直接联系开发者)。

诊断信息包含:程序版本、系统版本、磁盘剩余空间、Steam 是否安装等,**不含个人文件路径**。

## ⚠️ 已知说明

- PyInstaller 单文件 exe 可能被杀毒软件误报,添加信任即可
- 层3 启发式候选会包含少量正常软件(比如迁移过目录的软件),橙色标记 + 双重确认,请人工核对
- 删除 HKLM 注册表键、跨管理员操作时会弹 UAC,点「是」即可
